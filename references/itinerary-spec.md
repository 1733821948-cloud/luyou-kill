# 完整执行攻略规格

## 时间与动线

- 覆盖抵达目的地到返程离开的全部天数，以用户车票、航班、酒店、预约为锚点。
- 每天注明完整日期和星期。境外明确当地时区，跨夜、跨时区和夏令时切换重算日期及接驳。
- 日内精确到小时，重要预约、班次、演出与衔接到分钟。计划时刻与已核实班次清楚区分。
- 安排出门、到达、游览、三餐、交通、休息、回酒店；计入步行、候车、换乘、安检、取行李、寄存、入住退房与排队缓冲。
- 按相邻片区串联，比较酒店门到景点入口总耗时，减少跨区反复往返；为专程绕路说明实际取舍。
- 首尾日按抵离时间精排，换酒店或退房后落实行李运输寄存与取回。住宿信息围绕已定酒店组织。

页首速览：当天完整路线、主要项目、预计步行量、关键预约、随身物品与特别提醒。

表内按时间写清一天所有动作；细节多时在表后展开，避免长文挤进单元格。每天补充景点内部路线、逐餐点菜、必要交通细节、当天备用安排与费用小计。抵离日按当地实际覆盖餐段安排。

## 全部交通

| 方式 | 必备信息 |
| --- | --- |
| 步行 | 准确起终点、距离、时长、必要找路说明 |
| 公交/地铁 | 线路、方向、上下车站、换乘、必要且已核实的出入口、步行接入、耗时费用；涉及晚归查末班 |
| 打车 | 准确上下客点、导航目的地、预计耗时与费用、必要打车渠道 |
| 自驾/租车 | 路线名、里程、耗时、停车位置和费用、限行/景交换乘、取还车衔接 |
| 包车 | 当天路线、接送时刻地点、行程范围、待确认服务与费用 |
| 跨城 | 发到站全名、班次时间、合理提前量、两端接驳、行李与换乘手续 |

- 大型景区、车站、商场、博物馆核对入口和楼栋，写清导航搜什么、哪里下车、从哪里进入。
- 自驾/多点行程可汇总逐段里程、正常耗时、拥堵预留；路线详情仍落实至当天。
- 远郊、海岛、山地及散场查具体返程，提供打不到车的可靠替代。
- 公交卡、通票和套票根据最终路线计算是否划算，比较单买与组合总价、覆盖范围、有效期、预约及兑换限制。
- 根据用户指定交通分支安排；确需其他方式时交代理由和费用，避免默认人人自驾或人人坐公交。

## 景点内部

- 入口→核心游览顺序→出口；各处停留、必看与可舍弃、讲解及省力路线。
- 分别核实售票截止、最后入场、闭园、景交/索道/游船末班；演出和灯光秀按实际场次。
- 给出景交、索道、游船等使用办法，核对票种是否已含。
- 顺路拍照可补位置、时段、简单手机拍法，保持游玩为主线。

## 每餐

- 早餐、午餐、晚餐逐餐有具体主选店名/分店/位置、到店时间、推荐菜、按人数份量、人均、用餐与排队时长、预约需求。
- 给顺路可靠备选及何时切换；实在找不到时如实标缺口，避免编造店铺。
- 核对早餐结束、午晚市休息、最后点单、招牌菜供应和售罄；酒店含早据此排餐。
- 选中美食合理分配至正餐、小吃、下午茶等，避免重复堆餐；饮食禁忌与份量全程匹配。

## 预算与购买

- 分项行程预算不含用户已定往返大交通与酒店，按餐饮、门票、当地/途中新增交通、其他必要费用、机动金分类。阶段五补充将实际往返票和酒店费用并入整趟全包预算；单列当地支出与全包合计，避免重复加总。完整预估和超支判断见 total-budget.md。
- 人均、按车、按次、按间等单位一致，按实际人数算总计；未知项给范围或待补。
- 单列适用的景交、索道、讲解、寄存、停车、油费、过路费、税费、服务费、小费、支付手续费等隐藏成本。
- 核对套票包含项，避免重复计价。购物与伴手礼作为弹性项，不用其挤占必需项目预算。
- 境外当地币与人民币分开，注明参考汇率、查询日期与含税/未含口径。
- 查适用的官方消费券、票根优惠，说明领取、使用及有效期；资格按用户条件确认。
- 购票表列项目、状态、具体操作日期/放票时刻、渠道、票种、预约截止、未订到替代及重要退改截止。

## 每日备用方案

给出切换条件→替换具体项目→怎么去→如何接回后续行程：下雨、约满/闭馆、餐厅等位过久、晚出发半小时/一小时、疲劳、散场打不到车。

时间阈值根据当天固定预约与交通测算；先保护用户必选项，必要时说明相互冲突及需取舍之处。跨天、全局应急与当天局部替换分别归位，避免重复长段。

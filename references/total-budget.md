# 整趟费用预估与预算调整

## 执行位置与输入

在阶段五行程修改完成后、阶段六准备与注意事项前执行。基于最终路线及最新可靠费用资料，不擅自替换用户的已订票或酒店。

沿用八问第3项的实际往返票及酒店总费用、第5项不含这两项的其余预算，统一币种、人数、间数与晚数。可以先收机票酒店合计，无需强迫拆分；合计已含的附加费不能再次计入。

整趟预算目标＝用户提供的往返票及酒店实际总额＋其余预算。人均预算先按人数转换为全队金额，明示计算口径。用户明确给出的整趟最高接受金额优先，并同时保留原分项便于检查。

缺订单费用或预算时只补问缺口；先列可核实小计、未知项及其影响，不编造完整总额或预算充足结论。单独缺已付款信息不阻塞总费用评估。

## 按最终行程逐项估算

| 类别 | 计算方法 |
| --- | --- |
| 往返机票/车票 | 用户实际订单总额；核对行李及其他已含项目 |
| 酒店 | 用户实际订单总额；核查税费、早餐、停车等是否另收 |
| 当地与途中新增交通 | 每段地铁、公交、打车、包车、租车等按路线测算，含适用油费、停车与过路费 |
| 餐饮 | 按每天具体餐厅、推荐菜、人数估算，计入计划中的小吃、饮品、夜宵与适用税费服务费 |
| 景点与体验 | 适用票种及已选景交、索道、游船、讲解、演出，核对套票包含项 |
| 其他必要费用 | 实际适用的签证、网络、保险、寄存、支付手续费等 |
| 购物与伴手礼 | 用户自选额度单列，未给额度时不凭空假定消费金额 |
| 机动金 | 根据未确定费用、路线特点及变数说明建议金额和依据 |

每项注明单价、单位、数量、包含范围、已核实/估算/待核状态、来源与查询日。已含早餐、酒店税费、套票及预付项目避免重复计入。未决定购买的项目与自选购物单列，并给含/不含口径。

## 三个结果与付款情况

1. **正常预计总费用**：固定订单费加按当前方案最可能发生的其余费用。机动金作为备用资金另列，避免直接当作已发生消费。
2. **合理波动范围**：根据餐饮、打车、临时替代、汇率等变数形成可解释的低/高情景，包含相同项目范围；避免无依据地把所有极端上下限同时相加。说明是否含购物等弹性项。
3. **建议准备金额**：正常预计总费用加适当机动金；如另建议自选购物额度则清楚说明。说明这一金额与合理波动上限的关系，避免重复叠加同一风险。

机动金主要覆盖尚不确定的支出，依行程特点判断，不统一给全部已付固定费用机械加比例。真实订单和已核实票价照实际记，估算费用用合理范围。

已付资料齐全时分别列整趟预计总费用、已支付净额、预计还需支付；已付仍属于旅行总费用，不能再次作为待支付。另列建议留作备用的未支付机动金，避免用户误认为其为必须支出。

已付未知时标待确认，不默认机票酒店都已付款。可退押金/保证金作为额外资金占用单列，不直接当作最终消费；退款、退改损失与新订单按最终净成本核算。

境外同时展示当地币与人民币，固定订单按实际支付币种和用户提供人民币扣款记；其他项目按有日期的参考汇率换算，不对已支付金额重复按新汇率改价。

## 对照预算并给调整方案

同时比较正常预计、合理波动高端、建议准备金额与预算目标/明确总上限，给差额和主要变数。结论分为：

- **预算充足**：现有安排能保留，说明正常及波动情景的剩余空间。
- **正常预计能覆盖，但余量偏小**：说明可能超支的变数，建议增加多少备用资金或从哪些项调整多少。
- **预计超预算**：说明超出金额、主要原因，以及需要减少多少费用才能回到目标内。

明确预算覆盖正常消费还是连同备用金，避免用宽松口径判断正常消费、又用严格口径重复扣减余量。缺必需价格时结论保留条件和缺口。

每条调整写“改什么→预计净节省多少→时间/体力/体验影响”。先检查重复收费、不划算的票卡、绕路交通、可灵活调整的餐饮与非必选体验，优先保护用户必去/必吃及已确认节奏。

涉及已订机票酒店时算退改损失、旧订单实际退款、新订单和连带接驳费用，展示整体净变化，由用户决定，禁止只比较新旧标价。用户已明确不考虑更换时仅调整其他支出。

把费用结论及必要调整交给用户判断，按其确认或已有授权继续。调整后重新计算正常预计、区间、准备金额和差额，更新日程、每日费用及预算摘要。

## 后续同步

阶段六发现新必要费用或后续行程/订单改变时同步重算；足以改变预算结论或已确认取舍时向用户指出并提出具体处理。最终PDF准备部分包含最新全包预算与判断，已付/待付按可用信息列出，详细口径与当日费用一致。
